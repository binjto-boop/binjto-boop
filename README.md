### Leafy

Press <kbd>⌥A</kbd> over any word on your Mac screen and read what it means
without leaving the page. It reads pixels, not text fields, so a scanned PDF, a
screenshot or a subtitle works the same as a web page. Every lookup saves itself
with the sentence it came from.

10 study languages. Works offline. No account. Free while in beta.
